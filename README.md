## Selected projects

### [JalanJalan](https://github.com/ETHAN071104/JalanJalan)

Collaborative travel planning for groups. It combines realtime rooms, structured group preferences, place voting, and a deterministic scheduling engine that validates time, geography, opening hours, and travel constraints.

[Live demo](https://jlnjln.vercel.app) · [Presentation](https://youtu.be/T0j4UQ7uBC0)

### [Agentbook](https://github.com/ETHAN071104/CockroachDB-AWS-Hackathon)

An adaptive study workspace built with FastAPI, React, CockroachDB, vector retrieval, and workspace-scoped agent tools. Writes proposed by the learning agent require explicit confirmation.

### [Relay](https://github.com/ETHAN071104/webmcp-business-platform)

A multi-tenant service-business platform that exposes one capability model to both the customer website and browser agents through WebMCP. Booking integrity is enforced at the database layer.

[Live demo](https://webmcp-business-platform.vercel.app)

### [PROJECT ORIGIN](https://github.com/ETHAN071104/PROJECT-ORIGIN)

A browser-based educational RPG that teaches computer vision, machine learning, natural language processing, and deep learning through deterministic interactive simulations.

[Play online](https://project-origin-gold.vercel.app)

### [Visual Vocabulary](https://github.com/ETHAN071104/OpenAI-Build-Week)

A local-first image-learning application using ONNX Runtime Web, IndexedDB, Web Workers, editable segmentation masks, and a tested offline data model.
