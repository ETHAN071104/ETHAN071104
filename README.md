Genesis Studio is a multi-agent MVP builder that turns raw business ideas into structured, investable MVP blueprints.

It helps intrapreneurs, growth hackers, startup teams, and business innovators validate ideas, define MVP scope, and prepare stronger execution plans.

**Key ideas:**
- Multi-agent collaboration
- MVP scope control
- Product and business analysis
- Technical feasibility review
- Pitch deck and persuasion script generation

### ⚡ PACE

PACE is an AI-powered classroom quiz platform for teachers and students.

It helps teachers generate quizzes, verify real users, and monitor student activity during quizzes.

**Key features:**
- PDF-to-quiz generation
- Gmail verification
- Student quiz joining flow
- Real-time classroom quiz monitoring
- Teacher dashboard
